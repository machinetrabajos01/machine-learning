CONCEPT 01

What is Logistic Regression?

Logistic Regression is a supervised Machine Learning algorithm used mainly for classification problems.

It estimates the probability that an observation belongs to a particular class and uses a threshold to determine the final classification.

Key Idea

The model estimates a probability and converts that probability into a class.

Data → Probability → Threshold → Class

CONCEPT 04

Probability and Threshold

Logistic Regression produces a probability for each possible classification. A threshold is then used to determine the final class.

In binary classification, the prediction is commonly interpreted using a threshold of 0.5.

Classification Process

Probability → Threshold → Prediction
CONCEPT 05

Logistic vs Linear Regression

Logistic Regression

Used mainly for classification problems and produces probabilities associated with classes.

Classification

Linear Regression

Used to predict continuous numerical values such as house prices.

Prediction

Key Takeaway

Logistic Regression is a supervised classification algorithm that estimates probabilities and assigns observations to binary classes using a decision threshold.
