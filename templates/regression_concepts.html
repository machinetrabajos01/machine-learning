CONCEPT 01

What is Linear Regression?

Linear Regression is a Supervised Learning algorithm used to model the relationship between a dependent variable and one or more independent variables.

In Simple Linear Regression, the model uses one independent variable to estimate the value of one dependent variable.

Simple Linear Regression: One input variable → One predicted output.
Main Idea

Find a mathematical line that represents the relationship between two variables.

Y = β₀ + β₁X

The equation represents the relationship used by the model to generate predictions.

CONCEPT 02

What Problems Can It Solve?

Linear Regression is useful when the goal is to estimate a continuous numerical value.

💰
Price Prediction

Estimate a price based on measurable characteristics.

📊
Demand Prediction

Estimate future demand using historical quantitative information.

🌱
Environmental Analysis

Estimate environmental measurements based on related quantitative variables.

CONCEPT 03

Variables

Simple Linear Regression uses two main variables.

X

Independent Variable

The independent variable is the input used by the model to make a prediction.

Example: Population
Y

Dependent Variable

The dependent variable is the numerical value that the model attempts to predict.

Example: Waste Generation
CONCEPT 04

Relationship Between Variables

Linear Regression attempts to identify a linear relationship between the independent variable X and the dependent variable Y.

When changes in X are associated with changes in Y, the model can estimate this relationship and use it to make predictions.

Regression Line

The regression line is the line that represents the estimated linear relationship between X and Y.

The model calculates the line that best represents the observed data according to the Linear Regression objective.
