MACHINE LEARNING

Types of Machine Learning

Machine Learning can be divided into different approaches depending on how an algorithm learns from data and how feedback is provided.

🧠
OVERVIEW

Three Main Approaches

Each type of Machine Learning is designed for different kinds of problems and data.

🎯
TYPE 01

Supervised Learning

Supervised Learning uses labeled data, where the desired output is known during the training process.

Main Characteristics
  • Uses labeled datasets.
  • Learns a relationship between inputs and known outputs.
  • Can be used for prediction and classification.
Problems It Can Solve
Classification Regression
🔎
TYPE 02

Unsupervised Learning

Unsupervised Learning works with data without predefined labels and attempts to discover hidden patterns or structures.

Main Characteristics
  • Uses unlabeled datasets.
  • Discovers patterns and relationships.
  • Groups or organizes similar data.
Problems It Can Solve
Clustering Dimensionality Reduction
🎮
TYPE 03

Reinforcement Learning

Reinforcement Learning allows an agent to learn through interactions with an environment using rewards and penalties.

Main Characteristics
  • Learns through interaction.
  • Uses rewards and penalties.
  • Improves decisions through experience.
Problems It Can Solve
Decision Making Control Optimization
COMPARISON

How Are They Different?

The main difference is how the algorithm receives information and learns from it.

Type Data Main Goal Example
Supervised Labeled Predict or classify Predicting waste generation
Unsupervised Unlabeled Discover patterns Customer segmentation
Reinforcement Interaction and feedback Learn optimal actions Autonomous navigation
EXAMPLES

Real-World Applications

Supervised Learning

A company can use historical sales data to predict future sales.

Example: Sales prediction.
Unsupervised Learning

A business can analyze customer behavior and group customers with similar characteristics.

Example: Customer segmentation.
Reinforcement Learning

An autonomous system can learn which actions produce better results through repeated interaction.

Example: Autonomous control.

Key Takeaway

Supervised Learning learns from labeled examples, Unsupervised Learning discovers patterns in unlabeled data, and Reinforcement Learning learns through interaction and feedback.
