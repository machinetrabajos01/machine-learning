CONCEPT 01

What is Reinforcement Learning?

Reinforcement Learning (RL) is the type of Machine Learning in which an agent learns what to do by interacting with an environment. Nobody gives it the correct answers: it tries actions, receives rewards or penalties, and gradually prefers the actions that lead to the highest accumulated reward.

In our exercise a virtual robot starts in the top-left corner of a maze and must discover, on its own, a route to the target in the bottom-right corner while avoiding walls and Danger Zones.

Act → Observe the reward → Adjust → Repeat

CONCEPTS 02 – 07

Core Elements

The pieces of every Reinforcement Learning problem and what they are in our maze.

Agent

Whoever makes the decisions and learns. Here it is the virtual robot, shown as A at its starting cell {{ start }}.

Environment

Everything the agent interacts with: the 10 × 10 maze, its 20 walls, its 10 Danger Zones and the movement rules.

State

The situation the agent is in. Here it is the current (row, column), from {{ start }} to the target at {{ goal }}.

Action

What the agent can do in a state. There are four: Up, Down, Left, Right.

Reward

A number the environment returns after each action to say how good it was. Reaching T gives the only positive reward.

Penalty

A negative reward. Each step, each collision and especially each Danger Zone D subtracts points.

CONCEPTS 08 – 11

How the Agent Lives and Learns

Policy

The rule that tells the agent which action to take in each state. After training, our policy is: “in each cell, take the action with the highest Q-value”. Following it from A draws the learned path.

Step

One single interaction: the agent takes an action and the environment returns a reward and the next state. Example: from (0,0) the action Right leads to (0,1) with reward −1.

Episode

One complete attempt, from the start cell until the agent reaches T or uses its {{ config.max_steps }} allowed steps. Training runs {{ config.episodes }} episodes.

Experience

What the agent records in each step: (state, action, reward, next state). Each experience is used once to correct the model with partial_fit().

CONCEPTS 12 – 14

Exploration, Exploitation and Epsilon-Greedy

Exploration

Choosing a random action to discover the maze: new corridors, walls and Danger Zones the agent has not tried yet.

Exploitation

Using what is already known: choosing the action with the best estimated Q-value in the current cell.

Epsilon-Greedy

With probability ε explore, otherwise exploit. ε starts at {{ config.epsilon_start }}, is multiplied by {{ config.epsilon_decay }} after each episode and never drops below {{ config.epsilon_min }}.

Only exploring never uses what was learned; only exploiting can get stuck on the first route found, even if it crosses a Danger Zone. Epsilon-Greedy balances both.
CONCEPTS 15 – 20

From Rewards to Q-Learning

Open each item to see the idea and its meaning in the maze.

The reward received right after one action. Stepping on a normal cell gives −1; stepping on a D gives −15. Looking only at the immediate reward is short-sighted: every normal move looks equally bad, even the ones that approach the target.

The accumulated (discounted) reward from a moment until the end of the episode. This is what the agent really wants to maximise.

G = r₁ + γ·r₂ + γ²·r₃ + …

A route of 18 moves that avoids every Danger Zone collects 17 × (−1) + 100 = 83 points without discount.

A number between 0 and 1 that says how much future rewards are worth today. We use γ = {{ config.gamma }}: the +100 of the target is still worth a lot many steps earlier, so it can guide the agent from the start, but a reward that arrives sooner is always worth a bit more, which favours short routes.

The return the agent expects when it is in state s and keeps following its policy. Cells next to T have a high value; cells far away or surrounded by Danger Zones have a lower one. In our exercise V(s) is the best Q-value of the cell: V(s) = max Q(s, a).

The return expected when the agent is in state s, takes action a and then follows its policy. Each open cell has four Q-values, one per action. If Q((0,0), Right) is larger than the other three, the agent moves Right from the start. The Application page shows this table for every valid cell.

The algorithm that learns the Q-values from experience. After each step it moves Q(s, a) towards a target built from the reward and the best value of the next state:

target = r + γ · max Q(s′, a′)

In our implementation a scikit-learn SGDRegressor stores the Q-values: predict() estimates Q(s, a) and partial_fit() corrects it towards the target, one transition at a time.
