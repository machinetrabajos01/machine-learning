USE CASE 02

Email Spam Detection

Using Machine Learning to identify unwanted and potentially harmful email messages.

PROBLEM CONTEXT

The Problem

Email users receive large numbers of messages every day. Some messages are unwanted spam, advertisements, scams, or potentially malicious communications.

Manually identifying every unwanted message would be inefficient. Machine Learning can automatically analyze previous examples and identify patterns associated with spam.

Main Question
Is this email message spam or legitimate?
DATA

Data That Could Be Used

Email Text

Words and phrases contained in the email message.

Sender Information

Information about the sender and message origin.

Message Features

Links, keywords, message length, and other measurable characteristics.

MODEL OBJECTIVE

Classification

The model should classify each email into one of two categories.

Spam
Legitimate
MACHINE LEARNING TYPE

Supervised Learning

The model can learn from previously labeled emails where the correct category is known.

Classification
POTENTIAL BENEFITS

Why Use Machine Learning?

Automation

Automatically classify large numbers of incoming messages.

Time Saving

Reduce the time users spend identifying unwanted messages.

Security

Help identify suspicious or potentially harmful communications.

Key Takeaway

Machine Learning can learn from labeled email examples and automatically classify new messages as spam or legitimate.
