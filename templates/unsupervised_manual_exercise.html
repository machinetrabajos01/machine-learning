Manual simulation of the K-Means clustering algorithm using a student performance dataset.

EXERCISE OVERVIEW

Exercise Overview

This manual exercise demonstrates how the K-Means clustering algorithm works through three iterations.

The dataset contains 100 student records and two numerical variables: Study Hours and Exam Score.

The objective is to group students according to similarities between their study time and exam performance.

K-Means Process

The algorithm repeatedly assigns students to the nearest centroid and updates the centroid positions.

01

Assign

Calculate distances and assign each student to the nearest centroid.

02

Update

Calculate new centroid positions using the assigned students.

03

Repeat

Repeat the process and compare the final cluster configuration.

DISTANCE CALCULATION

Euclidean Distance

Distance Calculation

For each student, the Euclidean distance to each centroid is calculated.

d = √[(x₁ - c₁)² + (x₂ - c₂)²]

Each student is assigned to the cluster whose centroid has the smallest distance.

Assignment Rule

The calculated distances determine which centroid is closest to each student.

The smallest distance determines the assigned cluster.

K-MEANS PROCESS

K-Means Iterations

01

Iteration 1

Calculate the distance from every student to the three initial centroids.

Assign each student to the nearest centroid.

02

Iteration 2

Calculate new centroid positions using the students assigned to each cluster.

Recalculate distances and update assignments.

03

Iteration 3

Repeat the distance and centroid calculations using the updated cluster positions.

Compare the final cluster configuration.
