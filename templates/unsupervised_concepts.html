CONCEPT 01

What is Unsupervised Machine Learning?

Unsupervised Machine Learning is a branch of Machine Learning where algorithms analyze datasets without a predefined target variable.

The objective is to discover hidden structures, relationships, or patterns within the data.

Unlike supervised learning, the algorithm does not receive previously labeled classes. Instead, it identifies groups or structures based on similarities between observations.

Key Idea

The algorithm explores the data and discovers meaningful structures without predefined labels.

Data → Patterns → Clusters
CONCEPT 02

What is Clustering?

Clustering is an unsupervised learning technique used to group observations according to their similarity.

Each group is called a cluster. Observations within the same cluster should have similar characteristics, while observations belonging to different clusters should be more dissimilar.

01

Similarity

Observations are grouped according to similarities between their numerical characteristics.

02

No Target Variable

The algorithm works without a predefined target or class label.

03

Pattern Discovery

The objective is to identify hidden structures and meaningful groups within the dataset.

CONCEPT 03

K-Means Clustering Algorithm

K-Means is a clustering algorithm that divides observations into a predefined number of groups called K clusters.

In this workshop, K-Means is used to identify groups of students according to their academic performance and interaction with the Virtual Learning Environment.

01

Select K

Define the number of clusters that the algorithm must generate.

02

Initialize Centroids

Initial centroid coordinates are selected as the starting points of each cluster.

03

Calculate Distances

Euclidean distance is calculated between each observation and every centroid.

04

Assign Clusters

Each observation is assigned to the nearest centroid.

05

Update Centroids

New centroid coordinates are calculated using the observations assigned to each cluster.

06

Repeat

The process continues until the clusters become stable or the configured number of iterations is reached.

CONCEPT 04

Euclidean Distance

K-Means uses Euclidean distance to measure how close an observation is to each centroid.

d = √((x₁ − c₁)² + (x₂ − c₂)²)

Where x represents the observation and c represents the centroid.

Why Distance Matters

The nearest centroid determines the cluster assigned to each observation during the K-Means process.

CONCEPT 05

Centroids

A centroid represents the center of a cluster. Its coordinates are calculated from the mean values of the observations assigned to that cluster.

During each K-Means iteration, centroid positions can change as observations are reassigned to different clusters.

CONCEPT 06

Feature Standardization

The student performance application uses two numerical variables: Average Assessment Score and Total VLE Clicks.

Because these variables have significantly different numerical scales, StandardScaler is applied before training the K-Means model. 

from sklearn.preprocessing import StandardScaler

scaler = StandardScaler()

X_scaled = scaler.fit_transform(X)

Standardization prevents the variable with the larger numerical scale from dominating the distance calculations used by K-Means.

CONCEPT 07

Silhouette Score

The Silhouette Score evaluates how well observations fit within their assigned clusters compared with other clusters.

Its value ranges from -1 to 1. Higher values generally indicate better separation between clusters and greater similarity among observations within the same cluster.
