APPLICATION 01

Problem Context

The objective of this application is to classify residential properties into two price categories: Low Price and High Price.

Gradient Boosting uses several independent variables to identify patterns in residential property characteristics.

Target

The model predicts the price category of a residential property.

0 = Low Price
1 = High Price
APPLICATION 02

Dataset and Variables

The classification dataset contains 2,000 records related to residential properties.

Independent Variables
  • House_Area
  • Bedrooms
  • Bathrooms
  • House_Age
Target Variable

Price_Category
0 = Low Price
1 = High Price
