Linear Regression Application

Predicting house prices based on house area

Problem Context

This application demonstrates how Simple Linear Regression can be used to estimate the price of a house based on its area.

The model learns the relationship between house area and house price using a synthetic dataset created for academic purposes.

Regression Visualization

The scatter plot shows the relationship between house area and house price. The regression line represents the predictions generated by the trained model.

Machine Learning Model

The application uses the LinearRegression algorithm from scikit-learn.

model.fit(X, y)

The model is trained using House_Area as the independent variable and House_Price as the dependent variable.
